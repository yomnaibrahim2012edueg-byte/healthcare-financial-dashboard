# 🏥 Healthcare Financial & Revenue Overview Dashboard

## 📌 Project Overview
This Power BI dashboard provides a comprehensive financial performance analysis for healthcare operations. It tracks total revenue streams, insurance payer coverage, and monthly financial distribution to optimize revenue collection and minimize insurance coverage gaps.

## 🛠️ Tools & Technologies
- **Business Intelligence:** Power BI (DAX, Data Modeling, Data Visualization)
- **Data Source:** Healthcare encounters, patients, procedures, and insurance payer datasets

## 📊 Key KPIs & Insights
- **Total Revenue:** Generated over **$101.51M** in total hospital revenue.
- **Coverage Rate:** Overall insurance coverage rate stands at **30.63%**, with **$31.10M** covered by insurance payers.
- **Revenue Distribution:** Detailed breakdown of monthly revenue trends showing consistent performance across all quarters.
- **Payer Performance:** Breakdown of top insurance organizations (Medicare, Medicaid, Humana, Aetna, etc.) vs. uninsured patients.
